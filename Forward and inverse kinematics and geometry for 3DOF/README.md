# Forward and inverse kinematics and geometry for 3DOF

## Overview

This project focuses on the fundamental kinematic analysis and geometric modeling of a 3-Degree-of-Freedom (3-DOF) robotic arm. It covers both Forward Kinematics (Direct Geometry)—determining the position and orientation of the end-effector based on joint angles—and Inverse Kinematics, which calculates the required joint angles to reach a specific target position in 3D space, alongside Jacobian matrix evaluations.

Note: This project served as the foundational starting point for my Bachelor's Degree graduation project.

## Features

- Forward Kinematics (Direct Geometry): Implementation of Denavit-Hartenberg (D-H) conventions
- Inverse Kinematics: Analytical and numerical resolution methods to determine the joint configurations corresponding to target end-effector coordinates.
- Jacobian Matrix Analysis: Calculation of linear and angular velocities, mapping joint velocities to operational space velocities, and identifying singularities.
- Trajectory and Workspace Mapping: Numerical simulations to visualize the robot's reachable workspace and motion paths.

## Technologies Used

- Software & Environment: MATLAB.
- Mathematical Concepts: Homogeneous Transformation Matrices, Denavit-Hartenberg Parameters, Matrix Algebra, Trigonometric Kinematic Inversion, Jacobian Matrix.
