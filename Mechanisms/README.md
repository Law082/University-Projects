# Mechanisms and Kinematics: Articulated Linkages and Gear Trains

## Overview

A structural and kinematic analysis of a bi-contour articulated linkage mechanism and a compound planetary gear train.

## Features

- Mathematical derivation and graphical validation of motion functions ($\phi_3$, $s_5$) for a 1-DOF linkage mechanism.
- Dimensioning of unspecified mechanical links, ensuring the geometric conditions for a fully rotating crank are met.
- Design of a planetary gear stage combined with an external gear stage to achieve an exact transmission ratio of $i = 6.75$.

## Technologies Used

- Software: AutoCAD (graphical kinematic construction), MATLAB (solving non-linear vector loop equations).
- Concepts: Vector Loop Closure Equations, Willis Equation, mobility calculations.

## Results

- Successfully calculated and mapped the translational ($s_5$) and rotational ($\phi_3$) displacements across a full $360^\circ$ input cycle.
- Determined the exact number of teeth ($z_1$ through $z_5$) and the resulting geometric diameters required for the planetary gear train.
