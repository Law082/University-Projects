# Enterprise Workflow & Business Intelligence Suite (Power Apps, Power Automate & Power BI)

## Overview

This project delivers an integrated enterprise solution designed to streamline operational data collection, automate multi-step approval workflows, and provide real-time interactive business intelligence dashboards. The system bridges a custom-built low-code frontend with a robust cloud data repository and automated backend triggers.

## Features

- Custom Low-Code Interface (Power Apps): Built intuitive applications enabling users to input, manage, and track operational records seamlessly.
- Cloud Data Repository (SharePoint): Utilized SharePoint lists as a centralized backend data source for real-time operations and data management.
- Automated Business Logic (Power Automate): Designed automated cloud flows to handle conditional notifications, approval routing, and data synchronization.
- Executive Dashboards (Power BI): Connected live data feeds to generate dynamic, interactive graphs and visualizations tracking key performance indicators (KPIs).

## Technologies Used

- Frontend & Logic: Microsoft Power Apps, Microsoft Power Automate.
- Data & Storage: Microsoft SharePoint Lists.
- Analytics & Visualization: Microsoft Power BI (interactive dashboards and graphs).

## Architecture
The architecture integrates Microsoft ecosystem components into a cohesive business workflow:

- Data Input Layer (Power Apps): Users interacted with tailored forms to submit requests or update records.
- Storage Layer (SharePoint): Data was committed to centralized SharePoint lists, ensuring structured data integrity.
- Automation Layer (Power Automate): Background triggers executed automated workflows like approval requests and alerts.
- Reporting Layer (Power BI): Aggregated data streamed directly into Power BI reports to provide real-time graphical insights.

## Results 

- Successfully automated manual data entry processes, reducing administrative overhead and human error.
- Provided transparent visibility into operational metrics through real-time dashboards.
